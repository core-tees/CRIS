# Reference results

These files retain the principal measured timings, inverse construction costs, field errors and independent-step comparisons, together with final transport fields. They are reference measurements, not inputs to the example solvers. Fresh examples write their own measurements and plots to `runs/`.

Final fields are grouped by case and retain their recorded filenames. Within each trajectory prefix, only the last accepted field is retained. Completion and timestep histories matter when interpreting comparisons; the example runner records these in its summaries. Historical campaign logs, intermediate snapshots and publication layouts remain outside this code release.
